# Study MBBS Abroad - Responsive Landing Page

## 📌 Project Overview  
This project is a responsive landing page designed for "Study MBBS Abroad" admissions. It includes country listings, program details, an admission process, and a lead generation form.  

## 🎯 Features  
- **Fully Responsive** (Tailwind CSS for mobile-first design)  

## 🛠️ Technologies Used  
- **HTML5** (Semantic structure)  
- **CSS3 (Tailwind CSS/Bootstrap)** (Responsive design)  
- **JavaScript** (Interactive elements, form validation)  
- **PHP (Optional)** (For backend form handling)
